# The Wild Oasis
 
An internal hotel management tool for a small cabin hotel. I built it in 2023 while following Jonas Schmedtmann's React course.
 
## What it does
- Cabin CRUD with photo upload
- Bookings table with filtering, sorting and pagination
- Check in / check out
- Dashboard with sales and occupancy graphs over the last 7, 30 or 90 days
- Various hotel settings
- Employee accounts (Registration is internal)
- Dark mode
 
## Stack
React with Vite, React Router, styled-components, TanStack Query, React Hook Form, Recharts, Supabase backend
 
## Running it
The Supabase project has been down for a hot minute so running this project as-is will result in major issues.
